## 👋 Who am I

> **Most AI demos end the moment the model answers. That's where my work begins.**

I'm **Anchal Singh Parihar**, an AI engineer who builds LLM systems that check themselves before anyone has to trust them: an on-call agent that **rolls back its own failed fixes**, a data analyst that **refuses to guess** when it can't answer, and research on whether a model can tell **when a tool call actually helped**.

- 🛠️ **End to end:** I design, build, ship and run AI products: RAG pipelines and multi-step agents, LLM-backed APIs on FastAPI and PostgreSQL, shipped with Docker, Kubernetes and Helm in production-style setups, and monitored with evals, guardrails and Langfuse tracing
- 🔭 **Building now:** Rootvanta, an AI on-call engineer that diagnoses production incidents, applies the fix, verifies it against live metrics and rolls back on its own if the fix didn't work
- 🎯 **Open to:** AI Engineer · GenAI Engineer · ML / LLM Engineer · Backend Developer · Forward Deployed Engineer (FDE), internship or full-time
- 🎓 **Education:** B.Tech in Computer Science and Engineering, SRM University, Sonipat, Haryana · Class of 2027
